# Uninvited Landing Page

Build a single polished, responsive landing page for my game UNINVITED, matching the attached reference image as closely as practical in overall visual language and structure. This is for an IGDC submission, so prioritize visual quality and a convincing live page over backend functionality. Create the page at route /uninvited and make it easy for me to edit/replace all text, images, and video later. Do not add authentication, database, CMS, or other unnecessary features.

Design direction: dark, gritty detective/thief/puzzle-adventure aesthetic; near-black textured background, warm cinematic imagery, off-white hand-painted/brush-style headings, red accent strokes/highlights, subtle paper/tape/scrapbook treatment, thin separators, moody lighting. The page should feel handcrafted and premium, not like a generic SaaS template.

Match the reference section flow: hero with large UNINVITED title, tagline and CTA; What Is Uninvited section with text plus 3 image cards; Gameplay section with 4 steps; chapter/story section featuring Chapter 01 and The Jimmy's Parable; trailer section; gallery strip; game info; footer. Use placeholder assets where necessary, but structure every asset slot so I can easily swap them later. Include functional smooth-scroll navigation/buttons where relevant, but keep this as a simple marketing page.

Important: use the attached screenshot as the primary visual reference. Do not literally embed the screenshot as the page. Recreate the layout with proper HTML/CSS components. Ensure desktop looks very close to the reference and mobile is responsive while preserving the same atmosphere and hierarchy. Use accessible semantic markup. No placeholder lorem ipsum.
